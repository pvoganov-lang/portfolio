# Telegram-бот записи в студию красоты «Аура»

Бот, который заменяет администратора на телефоне: клиент сам выбирает услугу,
дату и время, а владелец получает уведомление в Telegram.

## Что умеет

- **Запись за 6 шагов**: услуга → дата → время → имя → телефон → подтверждение.
- **Проверка занятости**: занятые слоты не показываются, повторная запись на то же
  время невозможна (защита на уровне БД — уникальный индекс).
- **Мои записи**: клиент видит свои будущие записи и может отменить любую.
- **Уведомления владельцу**: новая запись и отмена приходят в личку админу.
- **Команда `/admin`**: список записей на сегодня и сумма выручки.
- **Телефон в один тап**: кнопка «Отправить номер» подставляет контакт из Telegram.

## Стек

- Python 3.10+
- [aiogram 3](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram Bot API
- SQLite (aiosqlite) — хранение записей, без отдельного сервера БД
- FSM — пошаговый диалог с валидацией на каждом шаге

## Структура

```
├── config.py        # услуги, цены, часы работы, токен из env

```

## Запуск

```bash
# 1. Зависимости
pip install -r requirements.txt

# 2. Токен от @BotFather и ваш Telegram ID (узнать: @userinfobot)
export BOT_TOKEN="123456789:AA..."
export ADMIN_IDS="123456789"

# 3. Запуск
python bot.py
```

Бот создаст файл `booking.db` при первом запуске.
