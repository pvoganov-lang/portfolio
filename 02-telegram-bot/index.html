Telegram-бот записи клиентов

Бот для студии красоты: клиент сам выбирает услугу, дату и время, оставляет имя и телефон, а владелец получает уведомление в Telegram. Занятые слоты не показываются.

Python 3aiogram 3SQLiteFSMasync/await

Как проходит запись

  1. Клиент нажимает «Записаться» и выбирает услугу из списка с ценами
  2. Выбирает день — показываются только свободные слоты
  3. Выбирает время: занятые часы исключены из клавиатуры
  4. Вводит имя и телефон (можно одной кнопкой из Telegram)
  5. Проверяет данные на экране подтверждения
  6. Запись попадает в базу, администратору уходит уведомление

Что внутри

Валидация на каждом шаге

Имя — от 2 до 40 символов, нормализация телефона в формат +7 (999) 123-45-67, дата не в прошлом.

Защита от двойной записи

Уникальный индекс в SQLite по дате и времени: два клиента не займут один слот даже при гонке.

Мои записи

Клиент видит свои будущие записи и может отменить любую — админу приходит уведомление.

Админ-команда

/admin показывает записи на сегодня и сумму выручки — без отдельной панели.

Фрагмент кода

@router.callback_query(Booking.confirm, F.data == "confirm:yes")
async def confirm_booking(callback: CallbackQuery, state: FSMContext) -> None:
    data = await state.get_data()
    service = SERVICES[data["service"]]

    booking_id = await store.add(
        user_id=callback.from_user.id,
        name=data["name"],
        phone=data["phone"],
        service=service.title,
        price=service.price,
        visit_date=data["visit_date"],
        visit_time=data["visit_time"],
    )
    await state.clear()
    await notify_admins(callback.bot, f"Новая запись №{booking_id}")
